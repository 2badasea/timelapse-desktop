사용 가이드

몇 시간짜리 녹화 영상을 원하는 길이의 짧은 타임랩스로 줄여주는 Windows 프로그램입니다. 설치 없이 압축만 풀면 바로 쓸 수 있어요.

x1 ~ x4096 배속 목표 길이 맞춤 앞뒤 자르기 여러 파일 한꺼번에 NVIDIA GPU 가속 Windows 10 / 11 · 64비트
OVERVIEW

한눈에 보기

OBS 등으로 녹화한 긴 영상을 골라 배속이나 원하는 길이만 정하면, 유튜브 쇼츠·인스타그램 릴스에 쓰기 좋은 짧은 타임랩스 MP4가 만들어집니다.

배속 또는 목표 길이

x1~x4096 13단계 슬라이더로 고르거나, 10·15·20·30·60초 중 원하는 결과 길이를 누르면 배속을 자동으로 맞춥니다.

앞뒤 자르기

녹화 시작·끝의 준비 화면을 빼고 원하는 구간만 변환합니다. 시작·끝 장면을 작은 그림으로 확인할 수 있어요.

여러 파일 한꺼번에

Ctrl·Shift로 여러 개를 고르면 차례로 변환합니다. 목표 길이를 쓰면 파일마다 배속이 따로 계산돼요.

실제 배속 미리보기

앞부분을 선택한 배속 그대로 짧게 변환해서 바로 재생합니다. 저장하기 전에 느낌을 확인하세요.

자동 최적 모드 · GPU 가속

영상을 분석해 가장 빠른 처리 방식을 고르고, NVIDIA 그래픽카드가 있으면 GPU로, 없으면 CPU로 자동 변환합니다.

진행률 · 완료 알림

진행률과 남은 시간을 보여주고 언제든 취소할 수 있습니다. 창을 내려놓고 있어도 끝나면 Windows 알림으로 알려 줘요.

01 · GETTING STARTED

시작하기

설치 과정은 없습니다. 압축을 풀고 실행 파일을 더블클릭하세요.

1

내려받기

GitHub 저장소의 Releases에서 TimeLapseConverter-v1.1.0-win-x64.zip 파일을 내려받습니다.

2

압축 풀기

zip 파일을 오른쪽 클릭 → 압축 풀기로 원하는 위치(예: D:\TimeLapseConverter)에 풀어 주세요. 이전 버전을 쓰고 있었다면 그 폴더는 지워도 되고, 설정은 그대로 이어집니다.

3

실행

압축을 푼 폴더에서 TimelapseConverter.exe를 더블클릭합니다. 바탕화면에 바로가기를 만들어 두면 편해요.

⚠ "Windows의 PC 보호" 창이 뜨면
개인이 만든 프로그램이라 코드 서명 인증서가 없어서 처음 실행할 때 파란 경고 창이 나올 수 있습니다. 창에서 추가 정보를 누른 뒤 실행을 누르면 됩니다. 다음부터는 뜨지 않아요. 공식 GitHub 저장소에서 받은 파일만 실행하세요.

03 · HOW TO USE

사용 방법

고르고, 길이를 정하고, 변환하면 끝입니다. 원본 영상은 읽기만 하고 절대 바꾸지 않아요.

1영상 고르기

왼쪽 목록에서 녹화 파일을 클릭하세요. 아래 초록 상자에 길이·해상도 같은 정보가 나오면 준비 완료입니다.

  • 목록에는 파일마다 영상 길이가 함께 표시됩니다.
  • 목록에 없는 파일은 다른 파일 열기…
  • 탐색기에서 영상 파일을 창 위로 끌어다 놓아도 바로 선택됩니다.
  • Ctrl·Shift를 누른 채 클릭하면 여러 개를 한꺼번에 고를 수 있어요 (7쪽).
  • 지원 형식: MKV, MP4, MOV

2배속 또는 길이 정하기

슬라이더로 배속을 고르거나, 목표 길이(10·15·20·30·60초)를 누르세요. 목표 길이를 고르면 영상 길이에 맞춰 배속이 자동으로 정해집니다.

  • 예) 1시간 10분 녹화 + 15초 → x281로 정확히 15초
  • 칩을 다시 누르거나 슬라이더를 움직이면 직접 고르기로 돌아갑니다.
TIP · 끌어다 놓기
탐색기에서 영상 파일을 끌어 프로그램 창 위에 올리면 파란 점선 안내가 나타나고, 놓는 즉시 선택됩니다. 여러 파일을 한 번에 끌어 놓으면 한꺼번에 변환할 수 있어요.

3앞뒤 자르기 필요할 때만

녹화를 시작하고 끝낼 때 찍힌 준비·정리 장면을 빼고 싶을 때 씁니다.

  • 막대의 두 손잡이를 끌거나, 시작·끝 칸에 3:00 · 1:08:20처럼 입력하고 Enter
  • 양쪽 작은 그림으로 그 시점의 장면을 확인할 수 있어요.
  • 자르면 목표 길이도 자른 구간 기준으로 계산됩니다.
  • 전체 구간을 누르면 처음부터 끝까지로 되돌아갑니다.

4미리보기로 확인하기

▷ 미리보기를 누르면 (선택한 구간의) 앞부분을 정한 배속 그대로 짧게(약 8초) 변환해서 새 창에서 반복 재생합니다.

  • 배속을 바꿔 가며 여러 번 확인해도 괜찮아요.
  • 미리보기 파일은 임시 폴더에 저장되고, 앱을 끄거나 [설정] → 임시 파일 → 지금 정리로 언제든 지울 수 있습니다.
구간을 정하는 요령
녹화 시작 직후 장면이 궁금하면 시작 손잡이를 조금씩 옮겨 보며 왼쪽 그림을 확인하세요. 손을 멈추면 그 시점의 장면이 바로 나타납니다. 정확한 시각을 알면 숫자로 입력하는 편이 빠르고, 초 단위로만 적어도(185 = 3분 5초) 됩니다.

5변환 시작

변환 시작을 누르면 진행률과 경과·남은 시간이 표시됩니다. 작업표시줄 아이콘에도 진행 막대가 나타나요.

  • 멈추려면 ✕ 작업 취소 — 만들던 파일은 자동으로 지워집니다.
  • 같은 이름의 결과 파일이 있으면 덮어쓰기 / 새 이름으로 저장 / 취소를 물어봅니다.

6완료

초록 상자가 나타나면 끝. 폴더에서 보기나 재생으로 바로 확인하세요. 다른 창을 보고 있었다면 Windows 알림과 작업표시줄 깜빡임으로 알려 줍니다.

04 · BATCH

여러 파일 한꺼번에 변환하기

1

Ctrl+클릭으로 하나씩, Shift+클릭으로 범위, Ctrl+A로 전부 고릅니다.

2

배속이나 목표 길이를 정하고 N개 변환 시작. 목록 순서대로 차례로 변환합니다.

3

끝나면 N개 변환 완료와 전체 용량이 표시됩니다.

목표 길이를 쓰면 파일마다 배속이 따로 계산돼 모두 같은 길이가 됩니다. 여러 파일은 각각 처음부터 끝까지 변환하고(앞뒤 자르기·미리보기는 한 파일만 골랐을 때), 하나가 실패해도 나머지는 계속 진행한 뒤 실패한 파일을 알려 줍니다.

변환 모드는 자동으로 골라집니다

모드적용 조건방식속도
정밀x16 미만모든 프레임을 읽고 N번째 프레임만 골라 가장 정확하게. 슬라이더 배속은 원본 프레임레이트 유지보통
고속x16 이상B-프레임을 건너뛰고 참조 프레임만 읽음. 30fps로 저장빠름
키프레임 고속배속 ÷ 30 ≥ 키프레임 간격키프레임(I-frame)만 읽음. 30fps로 저장가장 빠름

06 · SETTINGS

설정

오른쪽 위 ⚙ 설정을 누르면 열립니다. 바꾼 내용은 바로 저장돼요.

저장 폴더

변환된 영상이 만들어지는 곳. 변경으로 다른 폴더(외장 드라이브 등)를 고르고, 열기로 탐색기에서 엽니다. 바꾼 뒤에는 기본 폴더로 되돌리기가 나타납니다.

녹화 폴더

메인 화면 왼쪽 목록에 보여줄 폴더. OBS의 설정 → 출력 → 녹화 경로와 같게 맞춰 두면 녹화가 끝나자마자 목록에서 바로 고를 수 있습니다.

임시 파일

미리보기를 만들 때 생기는 파일의 개수와 용량이 표시됩니다. 지금 정리로 언제든 지울 수 있고, 앱을 종료할 때도 자동으로 정리됩니다.

변환 엔진

NVIDIA GPU 가속은 지원되는 PC에서만 켤 수 있습니다. 끄면 CPU로 변환해요. FFmpeg를 다른 위치의 것으로 쓰고 싶을 때는 FFmpeg 위치 지정.

기억하는 값

마지막에 고른 배속과 목표 길이는 다음 실행 때도 그대로 유지됩니다.

오른쪽 위 상태 표시 읽는 법

NVIDIA GPU 가속그래픽카드로 변환합니다. 가장 빠른 상태예요.
CPU 모드NVIDIA 그래픽카드가 없거나, 드라이버가 오래됐거나, [설정]에서 GPU 가속을 끈 경우. 변환은 정상적으로 됩니다.
FFmpeg 없음프로그램 옆 ffmpeg 폴더가 없을 때. 압축을 다시 풀거나 [설정] → FFmpeg 위치 지정.

설정은 %APPDATA%\TimelapseConverter\settings.json에 저장됩니다. 이 파일을 지우면 처음 상태로 돌아가요.

사양과 권장 환경

Windows 64비트 PC라면 대부분 실행됩니다. NVIDIA 그래픽카드는 있으면 더 빠를 뿐 필수가 아니에요.

프로그램 사양

버전1.1.0
운영체제Windows 10 / 11 (64비트)
설치필요 없음 (포터블). .NET 런타임과 FFmpeg 포함
용량압축 해제 후 약 445MB (프로그램 63MB + FFmpeg 382MB)
입력 형식MKV, MP4, MOV (H.264 · HEVC 등)
출력 형식MP4 (H.264), 원본 해상도 유지, 오디오 없음
화질고화질 고정 (GPU: CQ 18 / CPU: CRF 18)
출력 프레임레이트정밀 모드의 슬라이더 배속은 원본 그대로, 그 밖에는 30fps
배속x1, x2, x4 … x4096 (13단계) 또는 목표 길이 10 · 15 · 20 · 30 · 60초
편집앞뒤 자르기(초 단위), 여러 파일 차례로 변환
파일명 규칙원본파일명_64x.mp4 · 목표 길이를 쓰면 원본파일명_15s.mp4
인터넷사용하지 않음. 모든 처리는 내 PC 안에서만 이루어집니다

GPU 가속 — 내 PC도 되나요?

그래픽카드변환 방식설명
NVIDIA GeForce GTX 900 시리즈 이상
GTX 10·16, RTX 20·30·40·50 시리즈 등		GPU 가속NVIDIA 드라이버 570 버전 이상(2025년 이후)이 필요합니다. 오래된 드라이버라면 업데이트하세요.
NVENC가 없는 NVIDIA
GT 1030, 일부 노트북용 MX 시리즈 등		CPU자동으로 CPU 모드로 실행됩니다.
AMD Radeon · Intel 내장 그래픽CPU자동으로 CPU 모드. 결과 화질은 같고, 속도는 CPU 성능에 따라 다릅니다.
CPU 모드도 생각보다 빨라요
타임랩스는 프레임 대부분을 건너뛰기 때문에 시간 대부분이 "읽기"에 쓰입니다. 그래서 키프레임 고속 모드처럼 높은 배속에서는 CPU와 GPU의 차이가 크지 않습니다. 프로그램이 시작할 때 GPU 사용 가능 여부를 스스로 확인하고, GPU 변환이 실패하면 CPU로 자동 재시도합니다.

08 · NOTES & FAQ

주의사항과 자주 묻는 질문

!

압축을 푼 다음 실행하세요

zip 안에서 바로 실행하거나 exe만 따로 옮기면 영상 엔진(ffmpeg 폴더)을 찾지 못합니다. 항상 폴더째로 두세요.

!

녹화가 끝난 파일만 변환할 수 있어요

녹화 중인 파일은 길이를 읽을 수 없어 목록에 길이가 표시되지 않고, 고르면 "영상 정보를 읽지 못했습니다"가 나옵니다.

!

결과 영상에는 소리가 없습니다

빠르게 재생되는 타임랩스 특성상 오디오는 제거됩니다. 배경음악은 편집 프로그램에서 넣어 주세요.

!

작업 중 프로그램을 닫으면

확인 창이 뜨고, 종료하면 변환이 중단되며 만들던 파일은 삭제됩니다. 여러 파일 중 먼저 끝난 결과와 원본은 그대로예요.

!

백신 · SmartScreen 경고

서명 없는 개인 프로그램이라 경고가 뜰 수 있습니다. 공식 GitHub 릴리스에서 받은 파일이라면 [추가 정보] → [실행].

자주 묻는 질문

목표 길이를 15초로 했는데 15.1초가 나와요.
초당 30프레임 단위로 맞추느라 0.1초 안팎의 차이가 생길 수 있습니다. 구간이 목표 길이보다 짧으면 x1(원래 속도)로 변환돼요.
변환이 끝났는지 어떻게 알 수 있나요?
창을 보고 있으면 알림음과 초록 상자로, 다른 창을 보고 있으면 Windows 알림과 작업표시줄 깜빡임으로 알려 줍니다. 알림이 안 보이면 Windows 설정 → 시스템 → 알림에서 방해 금지가 꺼져 있는지 확인하세요.
미리보기 창이 까맣게 나오거나 재생이 안 돼요.
Windows N / KN 에디션은 기본 미디어 기능이 빠져 있습니다. 미리보기 창의 [기본 플레이어로 열기]를 쓰거나, Windows 설정 → 앱 → 선택적 기능에서 미디어 기능 팩을 설치하세요.
헤더에 "CPU 모드"라고 나와요. NVIDIA 그래픽카드인데요?
NVIDIA 드라이버를 최신(570 이상)으로 업데이트한 뒤 프로그램을 다시 실행하세요. [설정]에서 GPU 가속이 꺼져 있지 않은지도 확인해 주세요.
HDR(10비트)로 녹화한 영상도 되나요?
됩니다. GPU의 H.264 인코더가 10비트를 지원하지 않아 자동으로 CPU 변환으로 넘어가며, 결과는 일반(8비트) 영상으로 저장됩니다.
변환을 더 빠르게 하려면?
OBS 녹화 설정의 키프레임 간격을 2초 정도로 두면 x64부터 가장 빠른 키프레임 고속 모드가 적용됩니다. 노트북은 전원을 연결해 두세요.

이 프로그램은 영상 처리에 FFmpeg(GPL)를 사용합니다. 라이선스 전문은 ffmpeg\FFmpeg-LICENSE.txt에 있습니다.
